# PRALAYA: Multilingual Alerts & Vernacular Messaging

This module produces template-grounded emergency broadcasts across Odia, Bengali, Hindi, Telugu, and English.

## Pipeline
1. **Deterministic Slot Extraction**: Locks in evacuation deadlines, shelter destinations, and emergency contact numbers
2. **Template Slot Filling**: Uses NDMA/OSDMA pre-cleared advisory structures
3. **Gemini Vernacular Localization**: Natural, calm translation adhering to local coastal dialects
4. **Numerical Integrity Audit**: Verifies every digit and proper noun matches source data before dispatch
