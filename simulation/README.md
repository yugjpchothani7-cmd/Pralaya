# PRALAYA: What-If Disaster Simulation & Parametric Triggers

This module manages in-memory counterfactual disaster scenario sandboxing, allowing commanders to simulate sea level shocks, rainfall anomalies, and power grid failures.

## Capabilities
1. **In-Memory State Forking**: Clones active state vector without mutating persistent production databases
2. **Surrogate Re-Run**: Sub-second hydrodynamic surge re-calculation
3. **Parametric Insurance Evaluator**: Evaluates automated liquidity payout thresholds based on verified wind speed and flood coverage
4. **"What Changed?" Delta Diff**: Calculates spatial deviations and newly threatened assets between consecutive advisory files
